## 기준

<!-- rk: id=core -->
모델은 다른 층을 import 하지 않는다. 나머지 층은 모델을 향해서만 의존한다.

## 근거

의존이 한 방향이면 어느 층을 고칠 때 무엇이 깨질 수 있는지가 코드를 읽지 않아도 정해진다.
모델이 아무것도 모르면 모델을 바꾸는 일이 가장 비싸고, 그래서 가장 신중해진다.

## 예시

<!-- rk: role=counter-example -->
```ts
// src/model/block.ts
import { validateBlock } from '../validate/index.js' // 모델이 검사를 안다
```

```ts
// src/validate/checks/structure.ts
import { Block } from '../../model/index.js' // 검사가 모델을 안다
```

## 예외

<!-- rk: subject=[model] -->
모델은 mdast 의 타입만 타입 전용으로 가져다 쓴다. 런타임 의존이 아니므로 방향을 깨지 않는다.
