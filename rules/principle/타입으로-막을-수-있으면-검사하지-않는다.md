## 기준

<!-- rk: id=core -->
위반을 타입으로 표현할 수 없게 만들 수 있으면, 그 위반을 찾는 검사기를 두지 않는다.

## 근거

검사기는 늘어나면 서로를 모르는 채 겹치고, 실행 시점에만 말한다.
타입으로 닫아 두면 잘못된 코드가 애초에 컴파일되지 않으므로 검사기 하나가 통째로 사라진다.

## 예시

```ts
// 리프는 자식을 가질 수 없다 — 검사기 대신 타입
export interface Leaf extends Node {
  readonly children?: never
}
```

## 예외

런타임 입력(마크다운·YAML·에이전트가 보낸 JSON)에서 들어오는 값은 타입으로 막을 수 없다.
그것들은 경계에서 한 번 걸러 모델 안으로 들인다.
