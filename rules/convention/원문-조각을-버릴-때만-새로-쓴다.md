## 규약

<!-- rk: id=core -->
노드의 내용이 바뀌면 그 노드의 원문 조각을 null 로 만든다.

## 근거

직렬화기는 조각이 있으면 그것을 그대로 내보낸다.
바뀐 내용의 조각을 남겨 두면 파일에는 옛 내용이 되살아나고, 모델과 파일이 조용히 갈라진다.

## 예시

```ts
const bodyChanged = patch.text !== undefined || patch.source !== undefined
return new Block({ ..., raw: bodyChanged ? null : this.raw })
```

## 반례

<!-- rk: role=counter-example -->
```ts
// frontmatter 에 적히는 것이 바뀌었는데 조각을 남겼다
return new Document({ ...patch, raw: this.raw })
```

## 예외

본문과 디렉티브의 조각은 따로 둔다. 보조데이터만 고치면 본문 조각은 그대로 쓴다.
